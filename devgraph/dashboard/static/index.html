Neo4j

Credentials live in .env only. Display-only here — a live-reconnect on the dashboard's driver wouldn't propagate to the tray, watcher, or spawned MCP processes anyway, each of which builds its own GraphEngine at construction.

The Graph page's Cypher box no longer talks to Neo4j directly — it POSTs through this process's own /api/cypher endpoint (dashboard/routes.py), which runs the query server-side using this same config. The browser never sees a Neo4j credential.
